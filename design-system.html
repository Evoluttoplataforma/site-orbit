§4.5

Page wrapper recipe

Padrão para criar qualquer página dark nova no site. O body herda fundo branco do Tailwind v4 preflight — sem este wrapper, todo texto branco vira invisível e seções .section--light herdam o cinza-claro do dark e ficam ilegíveis. Copie o bloco abaixo no topo do html.ts e envolva todo o conteúdo em <div class="pg-dark">.

1. CSS wrapper · cole no <style> do html.ts

.pg-dark · .section-dark · .section-dark-soft 
.pg-dark { background: #0D1117; color: #C9D1D9; }
.pg-dark .section-dark { background: #0D1117; }
.pg-dark .section-dark-soft { background: #161B22; }
/* Anula herança do wrapper dentro de .section--light */
.pg-dark .section--light { color: var(--light-text); }
.pg-dark .section--light h2,
.pg-dark .section--light h3,
.pg-dark .section--light h4 { color: var(--light-text); }
.pg-dark .section--light p,
.pg-dark .section--light li { color: var(--light-text-secondary); }
.pg-dark .section--light .segment-card h3 { color: var(--light-text); }
.pg-dark .section--light .segment-card p { color: var(--light-text-secondary); }

3. Conteúdo do blog · sempre real, nunca inventado

import articlesData from '@/data/articles.json'

Os 6 cards do §5 saem do mesmo JSON estático que alimenta /blog. Sem imagens unsplash, sem títulos inventados. Se algum slug sumir do CMS, o .filter() ignora silenciosamente — build não quebra.

import articlesData from '@/data/articles.json';

type Article = { slug:string; title:string; category:string; cover_url:string|null };

const RELATED_SLUGS = [/* 6 slugs relevantes do tema da página */];

const RELATED_BLOG: Article[] = RELATED_SLUGS
  .map(slug => (articlesData as Article[]).find(a => a.slug === slug))
  .filter((a): a is Article => Boolean(a));

// No JSX/HTML string:
const blogCards = RELATED_BLOG.map(a => `
  <a href="/blog/${'$'}{a.slug}" class="knowledge-card">
    <div class="knowledge-card__image">
      <img src="${'$'}{a.cover_url || '/images/og-image.png'}" alt="${'$'}{a.title}">
      <span class="knowledge-card__type">${'$'}{CATEGORY_LABEL[a.category]}</span>
    </div>
    <div class="knowledge-card__body">
      <h4>${'$'}{a.title}</h4>
      <span class="knowledge-card__link">Ler artigo</span>
    </div>
  </a>
`).join('');
